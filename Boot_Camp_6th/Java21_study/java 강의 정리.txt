[java 프로그램 작성 및 실행하는 방법]

1. 소스코드 작성 
- Test.java
-- 첫글자는 대분자, .java
-- 내부는 영어로 구성 ( 사람을 위한 포맷 )
ex. public calss Test{..}

2.  컴파일 작업 ( 컴파일러로 작업 -- javac)
- 소스코드를 자가 알 수 있는 기계어로 번역
- 문법: javac Test.java ---------------> Test.class
-- javac를 통해 Test.java를 실행하라(컴파일 과정)
-- 결과물로는 Test.class가 생성됨
-- *.jar는 이 class 파일들을 압축한다
-- class 파일 == 바이트코드 : byte code
-- 바이트 코드는 기계어와 비슷한 java용 언어이다
-- class 파일은 어떤 os에서도 사용이 가능하다
==> java는 os에 독립적인 특징을 갖는다(플랫폼 독립적임)
-- class 파일은 JVM ( Java Virtural Machine )을 통해 기계어를 통해 실행되기 때문에 가능
-- JDK 설치하면 자동으로 JVM이 설치된다.

3. 실행 ( 인터프리터 이용 )
- *.class 를 실행해주는 명령어 
- 문법 :  java Test
-- java를 통해 Test.class를 실행하라 

실제로 직접 명령어를 입력해 실행할 일은 없음. 대부분 개발도구(ex. eclipse, intellij) 가 자동으로 해줌.

1. 식별자(identifier)
- 소스코드의 각 단어 의미.
- 종류 2가지 
	1. 시스템이 정의한 식별자 ( 예약어, 키워드 )
	- 시스템이 필요에 의해서 미리 정의한 단어
	- 마음대로 바꾸면 에러가 발생됨
	- ex) 
	public private protected
	class  void interface abstract 
	final static enum

	2. 사용자가 정의한 식별자
	- 예약어(키워드)와 같은 이름으로 사용불가
	- 대소문자 구별
	- 사용 가능한 3가지 요소
	가. 클래스명
		- 반드시 첫글자는 대문자로 지정(관례)
		- 의미있는 명사형 권장
		- 반드시 저장할 파일명과 일치해야야 된다
		- 첫글자 이후의 글자는 영소문자, 숫자, 특수문자 ( _, $ ) 가능
		ex. H12_World, H$World
	나. 변수명
		- 모두 소문자
	다. 메서드명

2. main 메서드
- 형식 : 	public static void main(String[] args) {}
- 용도 : 자바프로그램을 실행할 때 사용하는 시작점 역할 ( starting point )
- 특징 : 하나의 어플리케이션에는 반드시 단 하나의 main

	- 콘솔출력 ( console ) 출력
	2. 파일
	- output.txt
 	3. 네트워크
	- 채팅

- 표준 출력 : standard output 3가지
	1. 새로운 라인을 생성하여 출력
	- System.out.println(값);
	2. 새로운 라인 없이 출력됨 ( 한 줄에 출력된다 )
	- System.out.print(값);
	3. 특정한 포맷(format)형식으로 출력됨 ( 한 줄에 출력된다 )
	- System.out.printf("포맷형식", 값1, 값2, .... );
	
	포맷형식		값			예시
	---------------------------------------------------------------------
	%s		문자열 ( 반드시 "" 지정 )	ex. "hello"
	%c		문자 ( 반드시 ' ' 지정 )	ex. '남', 'A'
	%d		정수 			ex. 100
	%f		실수 			ex. 3.14
	%b		논리값			ex. ture, false

	출력포맷 [이름: 홍길동, 성별: 남, 나이: 20, 키: 184.3]
	System.out.printf("이름: %s, 성별: %c, 나이: %d, 키: %f", "홍길도", '남', 20, 184.3);

1. 자바의 데이터 종류
	2가지 종류가 있음
	자바입장에서 처리할 수 있는 데이터 종류
	
	1) 기본형 데이터(Primitive Data Type: PDT)	(8개)
				
		수치형 - 정수형	- byte	(1byte : 8bit)
									- short	(2byte : 16bit)
									- int		(4byte : 32bit)
									- long	(8byte : 64bit)
						////////////////////////////////////////////
							-10진수, 2진수, 8진수, 16진수 모두 사용가능
							  2진수: 0|1 이용 	(0b 앞에 붙음)	ex. 0b1
							  8진수: 0~7 이용	(0앞에 붙음)	ex. 01, 07
						 	 16진수: 0~9,A,B,C,D,E,F 이용 (0x 앞에 붙음) ex. 0x1, 0xf
							 
							- 큰타입의 정수( int(4byte)를 넘어가는 정수)는 반드시 마지막에 대문자 L을 붙임
							   ex. 987231653212123123L
							- 기본타입은 int(4byte)
						////////////////////////////////////////////
						
				실수형	- float	(4byte : 32bit)
							- double(8byte : 64bit)
						////////////////////////////////////////////
							- float 표현은 반드시 마지막에 F, f 지정해야 됨.
							  ex. 3.14F, 3.14f
							- double 표현은 마지막에 D, d 지정가능 
							  ex. 3.14D, 3.14d
							  
							- 기본타입은 double  
						////////////////////////////////////////////
						
		문자 - char(캐릭터) 		(2byte : 16bit)	
						////////////////////////////////////////////
							- 전세계의 모든글자 표현이 가능
							- 하나의 글자를 관리 ( 여러 글자(문자열)관리는 String 클래스가 관리)
							- 표현은 반드시 '' 지정해야 된다.
							  ex. '남', '여', 'M', 'F'
							- 이스케이프문자(escape 문자)
							  ex. '\n' : 키보드 엔터 효과, 줄내림
								  '\t' : 키보드 tab
								  '\"' : " 출력 (코드에서 "은 문자열 처리, 반드시 쌍으로 입력된다)
								  '\'' : ' 출력 (코드에서 '은 문자 처리, 반드시 쌍으로 입력된다)
								  '\\' : \ 출력
						////////////////////////////////////////////
						
		논리형 - boolean(불린)	(1byte : 8bit)
						////////////////////////////////////////////
							- 참/거짓 데이터 용도
							- 표현은 true, flase
						////////////////////////////////////////////
	
	2) 참조형 데이터	( 기본형 데이터형 제외한 나머지. Reference Dat Type: RDT )
		
		- 클래스
		- 인터페이스
		- 배열

2. 기본형 변수 vs 참조형 변수 	// 오늘 내용에서 가장 중요한 부분.

	1) 기본형 변수
	   기본형 데이터 8개를 저장하는 변수
	   ex. int num = 10;
	   
		num에는 실제 값인 10이 저장됨.
	   
	2) 참조형 변수
	   데이터 (클래스, 배열)를 저장하는 변수
	   ex. String name = "홍길동";
		
		name에는 "홍길동"이 저장된 주소값이 저장됨.
		
3. 변수 종류
	
	1) 데이터 종류에 따른 분류
		
		가. 기본형변수
		나. 참조형변수
		
	2) 변수 선언 위치에 따른 분류( 외우기 )
		- 기준은 메서드
			
			ex. 
				public class Test{
				
					# 메서드 밖
					int num;			# 인스턴스 변수
					static int size;	# 클래스 변수
					String name;		# 인스턴스 변수
			
					public void method(float x # 로컬 변수){
					# 메서드 안
					
						int count; // 로컬 변수, 가능하면 변수 선언과 동시에 초기화 하는걸 권장
					}
				}
		
		가. 로컬 변수 ( local variable )
			- 메서드안에서 선언
			- 생성시점: 메서드 실행
			  소멸시점: 메서드 실행이 끝나면 제거됨
			  생성횟수: 메서드 호출할때마다 매번 생성/삭제됨
			  
			- 저장메모리명: stack 메모리
			- 주의할점: 반드시 사용전에 초기화 필수 (********************)
			- 용도: 임시적으로 사용
			
		나. 인스턴스 변수 ( instance variable )	
			- 메서드밖에서 선언
			- 생성시점: 클래스 객체생성시 인스턴스변수가 생성됨
						ex. 
						클래스명 변수명 = new 클래스명();
						Test t = new Test();	// Test는 클래스이고 데이터로 처리되기 때문에 t 변수에 저장이 가능하다.
						
											  new Test() (객체생성)
						클래스(Test.class) ---------------------------> Test 인스턴스 (Test가 메모리에 올라간 상태)
 											  new Test() (객체생성)
										   ---------------------------> Test 인스턴스

6. 연산자 (operator)
	
	1. 산술연산자
		
		+	:	더하기
		-	:	빼기
		*	:	곱하기
		/	:	나누기 ex. 10/3 = 3 (기본), 10/3.0 = 3.333
		%	:	나머지 ex. 10/3 = 1
		
	2. 대입연산자
	   - 변수에 임의의 값을 할당(대입)할 때 사용
	   
	   a=b	:	a에 b를 저장(할당, 저장)
	   a+=b	:	a와 b를 더해서 다시 a에 할당
				(a = a + b)
	   a-=b	:	a와 b를 빼서 다시 a에 할당
				(a = a - b)
	   a*=b	:	a와 b를 곱해서 다시 a에 할당
				(a = a * b)
	   a/=b	:	a와 b를 나누어서 다시 a에 할당
				(a = a / b)
	   a%=b	:	a와 b를 나눈 나머지를 다시 a에 할당
				(a = a % b)
				
	3. 비교 연산자
	   
	   - 값을 비교하는 기능, 결과값은 받드시 논리값(true/false)로 변환, boolean타입으로 반환(**********)
	   
	   a==b	:	a와 b가 같냐?
	   a!=b	:	a와 b가 같지않냐?
	   
	   a>b	:	a가 b보다 크냐?
	   a>=b :	a가 b보다 크거나 같냐?
	   
	   a<b	:	a가 b보다 작냐?
	   a<=b	:	a가 b보다 작거나 같냐?
	   
	4. 논리 연산자
		
		- 논리값(true, false)을 이용해서 연산하는 기능, 결과값은 받드시 논리값(true/false)로 변환, boolean타입으로 반환(**********)
		
		1) &&
		   - and 연산자 (그리고)
			
			 true && true	: true
			 true && false	: false
			 false && true	: false
			 false && false	: false
		
		
		2) ||
		   - or 연산자 	(또는)
		   
		   	 true && true	: true
			 true && false	: true
			 false && true	: true
			 false && false	: false
		   
		3) !
		   - not 연산자 (부정 연산자)
		   
		     !true 	= false
			 !false	= true
			 
	5. 증감 연산자 ( 증가 연산자, 감소 연산자)
	
		- 임의의 변수값을 1씩 증가하거나 감소하는 기능
		
		문법1: 전치
				
				++변수명;	# 변수명 = 변수명 + 1 ==> 변수명 += 1;
				--변수명;	# 변수명 = 변수명 - 1 ==> 변수명 -= 1;			
		
		문법2: 후치
		
				변수명++;	# 변수명 = 변수명 + 1 ==> 변수명 += 1;
				변수명--;	# 변수명 = 변수명 - 1 ==> 변수명 -= 1;

7. 반복문

	용도: 조건식에 따라서 여러번 반복하는 문장
	종류: for문, while문, do-while문
	
	  ex. hello 문자열을 5번 출력하시오
	  
	  
	필요한 정보 3가지
		
		1) 시작값 필요: 변수로 정의해줘야 한다.
			ex. 1, 10, 100			
			int n = 1;			
		2) 증감 연산 필요: 증감연산자 사용		
			++n; (n++)			
		3) 조건식: 6에서 중단			
			n < 6
			
	* for문	// 회고_REF. 향상된 switch와 같이 for의 향상된 버전과 다른 반복문의 향상된 버전을 찾아보기
	
		용도: 반복횟수 예측이 가능할 때 주로 사용.

		문법:
			
			for(초기값 ; 조건식 ; 증감식){
			
				문장1;
				...			
			}
			
		ex. 
			for(int n = 1;n<6;++n){
				System.out.println();
			}
		
		특징:
			- 초기값, 조건식, 증감식이 서로 뭉쳐있음. 따라서 반복회수를 예측하기 쉽다.
			// 가독성이 높고 직관적이다.
			- 모든 제어문은 서로간에 충첩 가능하다.
			- 조건식이 처음부터 false인 경우 한번도 실행안됨.			
	
	* while문
		
		용도: 반복횟수 예측이 안될 때 사용.
			ex. 무한루프
		
		특징:
			- 조건식이 처음부터 false인 경우 한번도 실행안됨.(*********)		
		
		문법:
			
			초기값;
			
			while(조건식){

		- 추상메서드에서 abstract 키워드 필수 ( 생략불가 )

		라. static 메서드

			- 동작은 일반적인  static 메서드처럼 동작된다.

	3) interface 특징:
		- 불완전한 객체이기 때문에 직접 new 불가능

		- 다중구현가능: 상속과 다르게 하나의 클래스는 여러개의 인터페이스와 구현관계가 가능하다.

3. 람다 표현식(lambda expression)	// 람다식의 형태에 따른 표현 반식 표로 반들어서 작성

	1) 개념
		익명클래스의 또다른 표현 방법
		
	2) 등장배경
		자바에서는 클래스가 최소단위임	
		따라서 메서드만 필요해도 클래스를 필수로 생성해야 한다
		결국은 클래스 껍데기를 걷어내고 메서드에 집중.	( 함수형 프로그래밍 방법론 )
		
	3) 특징
		- 반드시 단 하나의 추상메서드만 가진 경우에만 람다표현식이 가능함.
		  ==> 단일책임원칙 방법론에 기반
		- 단 하나의 추상메서드만 가질 수 있도록 인터페이스를 강제 할 수 있음.
			@FunctionalInterface 어노테이션을 사용.
			
		ex.
			@FunctionalInterface	// 추상메서드만 반드시 하나 가지도록 강제한다.
			public interface Flyer{
				public abstract void fly();
				// default 메서드는 사용 가능
			}
			
	4) 람다표현신 4가지 문법
		- 인터페이스의 단 하나인 추상메서드가 파라미터 및 리턴타입 여부에 따른 문법
		
		가. 파라미터 없고 리턴타입 없음
			ex. 
				@FunctionalInterface
				public interface Flyer{				
					public abstract void fly();				
				}
				
				Flyer f = new Flyer(){
					public void fly(){
						System.out.println("fly()");
					}			
				};
				f.fly();
				
				// 람다표현식 (메서드에 집중)
				Flyer f2 = ()-> System.out.println("fly()");	// 하나의 실행문이면 {} 생략가능
				f2.fly();
						
		나. 파라미터 있고 리턴타입 없음
			ex. 
				@FunctionalInterface
				public interface Flyer2{				
					public abstract void fly(int n);				
				}
				
				Flyer2 f = new Flyer2(){
					public void fly(int n){
						@Override
						System.out.println("fly() = " + n);
					}			
				};
				f2.fly(10);
				
				// 람다표현식 (메서드에 집중)
				Flyer2 f2 = n -> System.out.println("fly() = " + n);	# 파라미터의 데이터타입 생략
																						# 파라미터 변수가 하나면 () 생략가능
		다. 파라미터 없고 리턴타입 있음										# 실행문 하나라 {} 생략
				ex. 
				@FunctionalInterface
				public interface Flyer4{				
					public abstract String fly();				
				}
				
				Flyer4 f = new Flyer4(){
					public String fly(){
						@Override
						return "Hello" ;
					}			
				};
				System.out.println(f.fly());				
				
				// 람다표현식 (메서드에 집중)
				// 아래와 같이 다수의 문장이 작성되면 {}, return 생략 불가
				Flyer4 f2 = () -> {
					System.out.println();
					return "Hello";
				};
				
				Flyer4 f2 = () -> "Hello";			# return 문장 하나만 존재하면 {} 와 return 생략 가능
				System.out.println(f2.fly());								
				
		라. 파라미터 있고 리턴타입 있음 
			ex. 
				@FunctionalInterface
				public interface Flyer5{				
					public abstract int fly(int n, int n2);				
				}
				
				Flyer5 f = new Flyer5(){
					@Override
					public int fly(int n, int n2){
						return n + n2;
					}			
				};
				System.out.println(f.fly(10,20));	
				
				// 람다표현식 (메서드에 집중)
				Flyer5 f2 = (int n, int n2) ->{return n + n2;};
				System.out.println(f2.fly(10,20));
				
				Flyer5 f3 = (n,n2) ->{return n + n2;};
				System.out.println(f3.fly(10,20));
				
				Flyer5 f4 = (n,n2) -> n + n2;						
				System.out.println(f4.fly(10,20));

1. 제네릭스 ( Generics )
	
	1) 개념
		- 다양한 타입을 다루는 메서드 및 클래스 
		- 컴파일 시점 (*)에 타입체크를 해서 예외를 미리 알 수 있도록 지원.
		
	2) 장점
		- 저장하는 데이터 타입 안정성 확보( 저장하는 데이터형을 제한 가능 )
		- 형변환 불필요
		
	3) 제네릭스 표현 방법( 타입 파라미터라고 부름 )
		<T>, <E>, <T,R>
		- <T>: Referenc Type 의미
			ex. <String>, <Integer>
		- <E>: Element 의미
		- <T,R>: Return Type 의미
			ex. <String, Integer>	// 파라미터: String, 리턴: Integer
		- <K,V>: Key, Value
			
	4) 특징
		- <T>가 컴파일 시전(*)에 실제 지정된 타입으로 치환됨
		- 클래스, 인터페이스, 메서드 파라미터에 사용 가능
		- static 사용불가, 객체생성불가

     - 메서드의 동작 방식에 따른 4가지 종류가 있음.
       가. 파라미터 없고 리턴값 없는 경우: 지원안됨
		 
       나. 파라미터 있고 리턴값 없는 경우:
					
				Consumer<T>			: 파라미터 한개(T 타입)                               
				BiConsumer<T,U>	: 파라미터 두개(T,U)
			   IntConsumer			: 파라미터 한개(int 타입)
			   DoubleConsumer		: 파라미터 한개(double 타입)
			   LongConsumer		: 파라미터 한개(long 타입)
			   ObjDoubleConsumer	: 파라미터 두개(T,double)		   

       다. 파라미터 없고 리턴값 있는 경우:
		 
				Supplier<T>			: 리턴 T
            BooleanSupplier	: 리턴타입 boolean
			   DoubleSupplier		: 리턴타입 double
			   LongSupplier		: 리턴타입 long                            

       라. 파라미터 있고 리턴값 있는 경우:

				DoubleToIntFunction		: 파라미터 한개(double), 리턴 int
			   DoubleToLongFunction		: 파라미터 한개(double), 리턴 long
				ToDoubleFunction<T>		: 파라미터 한개(T 타입), 리턴 double
				
				BiFunction<T,U,R>			: 파라미터 두개(T,U) , 리턴 R
				ToDoubleBiFunction<T,U>	: 파라미터 두개(T,U), 리턴 double
				---------------------------------------------------------
				Operator APi			: Function을 상속받는다.	
		      
				UnaryOperator<T>		: 파라미터 한개(T), 리턴 T
				DoubleUnaryOperator 	: 파라미터 한개(double), 리턴 double
				IntUnaryOperator 		: 파라미터 한개(int), 리턴 int
