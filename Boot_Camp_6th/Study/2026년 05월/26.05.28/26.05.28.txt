	14) 파일 및 디렉터리 복사
		
		가. 문법: cp [옵션] 원본 대상(target)
		
		나. 특징
			원본 및 대상파일: 파일이거나 디렉터리가 될 수 있음
			원본: 여러개 지정가능
			ex.
				cp 원본파일 타겟파일
				cp 원본파일1 원본파일2 ... 타겟 디렉터리
				cp 디렉터리 원본파일1 원본파일2 ... 타겟 디렉터리
				
				
		다. 옵션
			- i : interactive 기능, 덮어쓰기 유무를 묻는다
			- p : 원본파일이 속성(mode, 소유자, 시간)까지 유지되어 복사됨.
			- r : recursive, 원본에 디렉터리가 있는 경우 같이 복사
			
			
		실습1: 
			$ cp /etc/passwd ./users.txt
			$ cp /etc/passwd ./log1/users.txt	# 타겟에 복사될 디렉터리 포함가능.
		
			$ cp -i /etc/passwd users.txt			# 덮어쓰기 전에 물어봄
			cp: overwrite 'users.txt'? yes
			
			cp hello.txt users.txt first/  		# 있으면 복사되고 없으면 오류출력됨
			
			cp log2 users.txt first/				
			cp: -r not specified; omitting directory 'log2'		# -r 옵션을 붙이라는 경고문이 가이드가 뜬다
			
		실습2: -p		
			
			- users.txt의 소유자 확인:			
				ls -l | grep users.txt
				-rw-r--r-- 1 user1 user1 2907 May 28 10:04 users.txt
				==> 소유자: user1
				
			- 관리자 권한으로 복사:				
				sudo cp users.txt adminCopy.txt
				ls -l | grep adminCopy.txt
				-rw-r--r-- 1 root  root  2907 May 28 10:12 adminCopy.txt	# 
				==> 소유자: root
				
			- p옵션으로 복사:				
				sudo cp -p users.txt adminCopy2.txt
				ls -l | grep adminCopy2.txt
				-rw-r--r-- 1 user1 user1 2907 May 28 10:04 adminCopy2.txt
				==> 소유자, 생성시간이 원본과 동일

	15) 파일 및 디렉터리 이동 및 이름 변경
		
		가. 문법: mv [웁션] 원본  대상(타겟)
			ex. 
				mv 원본파일 타겟파일		# 이름변경
				mv 원본파일1 원본파일2 ... 타겟 디렉터리
				mv 디렉터리 원본파일1 원본파일2 ...  타겟 디렉터리
				
		나. 옵션
		
			- i : interactive 기능, 이동 여부를 묻는다
			- v : verbose, 특정 명령을 실행시 더 자세하게 과정을 보여주는 옵션
			- n : no overwrite, 기존파일이 있으면 덮어쓰지 않음
			- u : 원본 파일이 대상 경로의 파일보다 최신일 때(또는 대상 파일이 없을 때)만 이동

	17) 파일 찾기
		
		가. 문법: find 경로 [옵션] 대상(타겟)
		
		나. 옵션:			
						
			- name : 이름검색 ( 대소문자 구분 ) 			
			- iname : 이름검색 ( 대소문자 무시 ) 			
			- type f : 파일			
			- type d : 디렉터리			
			- size 크기 : 파일크기 기준			
			- user 사용자 : 사용자 기준			
			- exec 명령어 : 명령어 실행			
			- delete : 삭제			
			- ls : find 후에 ls 실행			
			- maxdepth n : 깊이 제한
			
			
		# 실습1:
			
			mkdir projects
			touch projects/report.txt
			touch projects/todo.txt
			touch projects/todo2.txt
			touch projects/error.log
			touch projects/alert.log
			
			echo	"todo" >> projects/todo.txt
			echo	"error" >> projects/error.log
			echo	"alert" >> projects/alert.log
			
			$ find projects -name todo.txt

			$ find projects -name Todo.txt	# 대소문자 구별됨

			$ find projects -name to*.txt		# 와일드카드 가능

			# 권한 설정 가능, 하위 디렉토리도 검색해서 보여준다, 키워드(ls) 중첩 가능
			$ sudo find /etc -name passwd -ls 
			395649      4 -rw-r--r--   1 root     root           92 Feb 22  2024 /etc/pam.d/passwd

	19) 하드링크 (hard link)
		가. 개념: 같은 inode 값을 갖는 다른 파일 
			////////////////////////////////
				inode란
				- 리눅스가 관리하는 자원(파일, 디렉터리, 장치,...)의 실제 저장되는 주소값 의미
			////////////////////////////////
			
		나. 문법: ln 원본 대상(타겟)
		
		다. 특징:
			- 디렉터리 지정 불가 ( 디렉터리는 동일한 주소값을 가질 수 없기 때문)
			- inode가 같으면 데이터도 동일
			- 한쪽이 수정되면 다른쪽도 영향을 받는다( like 자바 깊은복사 )
			- 한쪽이 삭제 되어도 다른쪽에는 영향이 없다
			  ( 삭제: inode 참조하는 링크를 삭제하는 것 )
			- inode를 삭제하면 링크된 파일 전체가 삭제된다.
		
		라. 목적
			- 백업용도: 하나를 삭제해도 나머지는 유지
			- 보안이슈: 중요한 파일명을 노출하지 않을 수 있음
			
		실습:
			echo "hello" >> main.txt		# 원본파일
			ln main.txt main_copy.txt		# 하드링크 파일
			$ ls -il | grep main
			787438 -rw-rw-r-- 2 user1 user1    6 May 28 14:24 main_copy.txt
			787438 -rw-rw-r-- 2 user1 user1    6 May 28 14:24 main.txt
			==> inode가 동일하다, inode 링크 갯수: 2
			
			$ cat main.txt main_copy.txt	# 내용이 같은지 확인
			$ echo "world" >> main.txt		# 원본 파일 수정
			$ cat main_copy.txt
			hello
			world
			
			$ rm main.txt						# 원본 삭제
			$ ls -il | grep main
			787438 -rw-rw-r-- 1 user1 user1   12 May 28 14:27 main_copy.txt
			==> inode는 유지되며, inode 링크 갯수가 줄어든다.
			
	20) 소프트링크 (soft link)
		가. 개념: 바로가기 기능 ( 윈도우에서 바로가기 기능: 원본이 삭제되면 바로라기 아이콘이 깨짐)
		
		나. 문법
			ln -s 원본 대상(타겟)
			
		다. 특징
			- 디렉터리 가능
			- inode가 다름
			- 원본 수정하면 영향을 받는다.
			- 원본을 삭제하면 대상의 링크가 깨진다. ( ls 입력시 빨간색으로 출력됨, 해결: rm 소프트링크 )
		
		라. 목적: 경로단축
		
		# 실습
			$ echo "hello" > m2.txt
			$ ln -s m2.txt m2_soft.txt
			$ ls -il | grep m2		# inode가 서로 다름 
			787440 lrwxrwxrwx 1 user1 user1    6 May 28 14:45 m2_soft.txt -> m2.txt		
			787439 -rw-rw-r-- 1 user1 user1    6 May 28 14:44 m2.txt
			==> inode 다름, 링크 갯수는 각 1개, ` -> ` 표시는 softlink를 의미한다
			
			$ echo "m2.txt update" >> m2.txt		# 원본수정
			$ cat m2_soft.txt							# 소프트링크 파일도 원본의 영향을 받는다
			hello
			m2.txt update
			
			$ rm m2.txt	# 원본삭제
			$  ls -il
			787440 lrwxrwxrwx 1 user1 user1    6 May 28 14:45 m2_soft.txt -> m2.txt
																			  ---------------------
																				터미널에서 이부분이 빨간색
																				==> 링크가 깨진 상태이다.
			
			$ rm m2_soft.txt 		# 원본과 링크가 깨졌으므 삭제해야 한다.
			
		# 실습: 디렉토리에 소프트링크 지정
			$ mkdir temp
			$ touch temp/test.txt
			$ ln -s temp temp_soft
			
			$ ls temp_soft
			test.txt
			
			$ ls -il | grep temp
			787439 drwxrwxr-x 2 user1 user1 4096 May 28 15:07 temp
			787442 lrwxrwxrwx 1 user1 user1    4 May 28 15:07 temp_soft -> temp

	21) 파일묶음과 압축하기 
		가. 파일묶음
			- 목적: 여러 파일들을 묶어줌 ( 압축 X, 크기변경 X )
			- 문법:
			
				# 묶는 방법
				tar -cvf 묶음.tar 파일명1, 파일명2, ....
				 	c: creat,
					v: 자세하게,
					f: file 지정
					
				# 해제 방법
				tar -xvf 묵음.tar				# 옵션 알아보기
		
		나. 압축하기
			- 목적: 파일 압축 ( 크기 변경됨 )
			- 문법:
			
				# 압축하기
				gzip 파일명 ==> 파일명.gz		
				
				# 압축해제
				gzip -d 파일명.gz
		
		다. 파일묶음 + 압축하기 (*****)
			- 여러파일은 묶고 파일압축
			
			- 문법: 
					# 묶고  압축하기
					tar -czvf 파일명.tar.gz 폴더
					
					# 해제 하기 
					tar -xzvf 파일명.tar.gz ==>  기본적으로 현재 디렉터리에 풀림
					tar -xzvf 파일명.tar.gz -C 폴더 ==> 지정된 폴더에 압축해제
		
			#실습
			
				$ tar -czvf project.tar.gz projects
				$ rm -rf projects
				$ tar -xzvf project.tar.gz project
				
				$ ls -l | grep project
				drwxrwxr-x 3 user1 user1 4096 May 28 13:46 projects		
				-rw-rw-r-- 1 user1 user1  225 May 28 15:21 project.tar.gz

1.파이프( Pipes )	
	
	가. 문법: 
		명령어1 | 명령어2
		
	나. 동작 :  명령어1의 출력결과를 명령어2의 입력으로 전달함
	
		ex. 
		# 현재 실행중인 프로세스중에 java가 있는가
			ps -ef | grep java		
			
		# ls -lhs을 위에서 20개만
			ls -lhs /etc | head n 20
			
		# auth.log이 바이너리 파일, grep은 ascii text 파일만 읽을 수 있기때문에 -a를 옵션이 필요하다.
			cat -n /var/log/auth.log | grep -a "authentication failure"
			cat -n /var/log/auth.log | grep -a "authentication failure" | wc -l
		
			
			////////////////////////////
			 # word count
			 wc -l : 라인수
			 wc -w : 단어수
			 wc -m : 문자수
			 wc -c : 바이트수
			 
			 ex.  wc -l /etc/passwd			
			////////////////////////////
