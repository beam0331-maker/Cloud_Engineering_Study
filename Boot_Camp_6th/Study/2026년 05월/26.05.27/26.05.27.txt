1. 프롬프터와 홈디렉터리
	
	1) 프롬프터(prompt) 개념
		- 사용자의 명령을 기다리는 표시.
		- ubuntu의 프롬프트 기본은 다음과 같다.
		
		 user1@ubuntu: ~$
		 
		user1: 사용자 계정
		ubuntu: 호스트명 # cal /etc/hosetname 에서 확인 가능.
		~ : user1의 사용자의 홈디렉터리 경로
			/home/user1
			
		$: 일반 사용자에서 사용하는 쉘프롬프트
			일반 사용자가 할 수 있는 작업들
				- 프로그램 실행.
				- 파일생성
				- 자신만의 홈디렉터리( ex. /home/user1 )안에서만 작업이 가능(****)
				
		#: root(관리자)에서 사용하는 쉘프롬프트
			root 사용자가 할 수 있는 작업들
				- 시스템 전체 권한을 가져서 모든 작업들을 처리가능.
				- 사용자생성
				- 패키지 설치 ( apt install, apt remove 등 )
				- 서비스 시작/종료
			
		- 프롬프트에 많은 정보를 얻을 수 있음
		ex. 현재 사용자, 호스트명, 현재경로, 현재 쉘
	
	2) 쉘과련 정보 얻기
		- 현재사용자 조회: whoami
		- 호스트정보: hosetname
		- 현재 쉘정보: 환경변수에 쉘정보 저장. SHELL = 쉘	( 윈도우에서 %JAVA_HOME%, Linux에서는 $SHELL)
							echo $SHELL
							/bin/bash ( 배시 쉘: 기본 쉘이다)
		
		- 프롬프트 포맷: 환경변수에 쉘정보 저장. ps1 = 프롬프트포맷
								echo $PS1
								변경가능. ( exprot PS1 = "변경값" )

2. 일반사용자에서 관리자로 변경하는 방법
	
	1) 한번만 관리자로 변경해서 실행 ( 초보자에게 권장 )
		
		- sudo 명령어
		ex. sudo apt update
			 sudo apt install
			 
	2) root로 쉘 변경 ( $ -------> #)
	
		가. 현재 사용자 경로를 유지하고 관리자로 변경하는 방법.
		
			문법: sudo -s ( sudo su 와 유사 )	

			root@ubuntu: /home/user1# apt update <== sudo 없이 실행가능.
		
		나. root 계정으로 변경하는 방법
			
			문법: sudo su -

			ex.
				user1@ubuntu:~$ sudo su -
				root@ubuntu:~# pwd
				/root			
		
		
	3) root 계정 인증한 캐시 삭제.
	
		문법: sudo -k
	
	/////////////////////////////////
	# su 명령어
	
		기능: 사용자 변경
		문법: 
				su					: 관리자로 변경
				su 사용자명		: 환경을 유지하고 사용자만 변경
				su - 사용자명	: 사용자가 바뀌며 사용자 환경( 사용자 계정의 홈디렉터리)으로 변경된다.

4. 터미널 명령어
			 
	1) tab 키 활용
		- 파일이나 디렉토리 입력시 많이 사용됨.
		
	2) 터미널 단축키
	
		- 화면 클리어			 : ctrl + l
		
		- 커서 앞 명령어 삭제 : ctrl + u
		  커서 뒤 명령어 삭제 : ctrl + k
		  
		- 커서 맨 앞으로 이동 : ctrl + a
		  커서 맨 뒤로 이동	 : ctrl + e
		  
		- 히스토리(history)에서 검색 : ctrl + r 에서 찾는 명령어 검색. esc로 빠져나오기
		
	3) 명령어 히스토리
	
		- 개념: 터미널에서 사용했던 명령어들은 저장되어 있다.
				  화살표키로 확인가능
				  
				  명령어는 history로 확인 가능
				  삭제: history - c ( 현재 터미널의 메모리에 저장된 history 정보만 제거 )
				  
				  ex.  $history
						 1  ipconfig
						 2  ifconfig
						 3  ping 8.8.8.8
						 ...
						 
					history가 저장된 물리적인 파일: ~/.bash_history
					history 완전 삭제 : rm -rf ~/.bash_history
											  ( 다시 접속하면 재생성된다 )
											  
		- !번호	: 지정된 번호에 해당하는 명령어가 실행됨
		  !!		: 방금 실행된 명령어를 다시 실행
		  !글자	: 지정된 글자로 시작하는 명령을 실행. ( 자동완성 지원X )
		  
		- $ " "명령어 : history에 명령어 저장 안됨

/////////////////////////////////////////////////		
	
	1) 개념
		- 데이터를 저장/검색/삭제 등을 관리함
		- Linux의 모든 것을 파일로 취급함 ( 장치 ex. usb, HDD,... , 디렉터리,  )
	
	2) 파일 종류
	
		가. 일반파일
			- 데이터를 저장하는데 사용.
				ex. 텍스트파일, 이미지파일 등.
		나. 디렉토리
			- 일반파일을 관리용이하도록 사용함.
			- 디렉터리 자체도 파일로 관리됨(****)
			
		다. 심볼릭 링크
			- windows의 바로가기가 비슷한 기능
			- 하드링크와 소프트링크
		
		라. 장치파일
			- usb, 하드디스크 등도 모두 파일로 처리한다
			ex. /dev/sda
				 /dev/sdb
				 ...
				 
	3) 파일종류 확인방법
	
		가. file
		
			문법: file 경로
			
			ex. 
				$ file /etc/passwd		# paswd: 사용자 정보가 들어 있다
				/etc/passwd: ASCII text

				$ file /etc
				/etc: directory
				
				user1@ubuntu:/dev$ file /dev/sda
				/dev/sda: block special (8/0)
				
				# 표준 입력/출력/에러
				$ file /dev/stdin		# 0번 자바의 
				$ file /dev/stdout	# 1번
				$ file /dev/stderr	# 2번
				
		나. ls -F		
		
			/: 디렉토리 의미
			@: 심볼릭 링크 의미
			*: 실행파일 의미
			이외: 일반파일 의미

	4) 디렉터리 계층 구조
		
		- 리눅스에서 윈도우 처러 C:\, D:\ 같은 드라이브 개념이 없다.
		- 단일 계층 구조로 관리하고, 시작은 /(root 디렉터리)이다.
			
							/( root )		==> root계정의 /root가 아니다
							|
			bin 	etc 	usr 	home 	tmp 	dev
									|
									user1
		
		- 현재 디렉터리: . 
		  부모 디렉터리: ..
		
		- 주요 디렉토리
		
			/bin	:  명령어 저장
			/home	:	일반 사용자 홈디렉터리 ( ex. /home/사용자명 ) 
			/root	:	root 사용자 홈디렉터리
			/usr	:	응용 프로그램
			/var	:	로그/변경 데이터
			/tmp	:	임시 디렉터리
			/etc	:	리눅스 설정파일	( ex. /etc/passwd. /etc/shadow )
			
		- 디렉터리 계층구조 쉽게 관리가능한 패키지.
			sudo apt update & sudo apt install tree 
			
			~$ tree
			~$ tree -d

	5) 홈 디렉토리 ( home directory )
	
		가. 개념
			- 사용자에게 할당된 디렉터리임. 처음 사용자(계정)을 생성할 때 제공됨.
			- 기본디렉터리는 /home/사용자명 으로 만들어짐. ( 경로 수정 가능 )
			- 홈디렉터리는 ~로 표시.
			- 홈디렉터리는 환경변수로 관리. HOM = /home/user1
				
				echo $HOME
				
		나. 홈 디렉터리 경로
			- 일반 사용자 홈디렉터리 : /home/사용자
			- root 사용자 홈디렉터리 : /root
			
			=> 리눅스는 일반사용자와 root  사용자의 홈디렉터리를 명확하게 구별하여 관리함. ( 보안 이슈 )
