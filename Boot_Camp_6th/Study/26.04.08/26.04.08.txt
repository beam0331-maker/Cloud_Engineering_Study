1. 중첩클래스
	
	1) 개념: 클래스 내에 또 다른 클래스를 정의
				inner 클래스 내부의 멤버는 static을 가지지 못한다.
		구조: 
			ex. public class Outer{
				
				// 변수, 메서드, 생성자
				
				class Inner{	// 중첩클래스(Inner 클래스)
					// 변수, 메서드, 생성자
					// static를 선언하지 못한다.
				}
				
			}
			
	2) 종류 4가지
		
		가. member inner 클래스
			-	outer 클래의 멤버처럼 정의된다.
			ex. 
				public class Outer{
					// 변수, 메서드
					public class Inner{
					}
				}
			
		나. local inner 클래스
			- Outer 클래스의 로컬변수 처럼 정의됨.	// 거의 사용되지 않음
			ex. 
				public class Outer{
					public void a(){
						int n = 10; // 로컬 변수
						class Inner{}
					}
				}
		다. static inner 클래스.
			- 일반적인 중첩클래스는 static을 못가짐.
			  대신 static inner클래스를 가질 수 있음.
		ex. 
				public class Outer{
					// 변수, 메서드
					static class Inner{
						static int num =10;
					}
				}

3. 람다 표현식(lambda expression)	// 람다식의 형태에 따른 표현 반식 표로 반들어서 작성

	1) 개념
		익명클래스의 또다른 표현 방법
		
	2) 등장배경
		자바에서는 클래스가 최소단위임	
		따라서 메서드만 필요해도 클래스를 필수로 생성해야 한다
		결국은 클래스 껍데기를 걷어내고 메서드에 집중.	( 함수형 프로그래밍 방법론 )
		
	3) 특징
		- 반드시 단 하나의 추상메서드만 가진 경우에만 람다표현식이 가능함.
		  ==> 단일책임원칙 방법론에 기반
		- 단 하나의 추상메서드만 가질 수 있도록 인터페이스를 강제 할 수 있음.
			@FunctionalInterface 어노테이션을 사용.
			
		ex.
			@FunctionalInterface	// 추상메서드만 반드시 하나 가지도록 강제한다.
			public interface Flyer{
				public abstract void fly();
				// default 메서드는 사용 가능
			}
			
	4) 람다표현신 4가지 문법
		- 인터페이스의 단 하나인 추상메서드가 파라미터 및 리턴타입 여부에 따른 문법
		
		가. 파라미터 없고 리턴타입 없음
			ex. 
				@FunctionalInterface
				public interface Flyer{				
					public abstract void fly();				
				}
				
				Flyer f = new Flyer(){
					public void fly(){
						System.out.println("fly()");
					}			
				};
				f.fly();
				
				// 람다표현식 (메서드에 집중)
				Flyer f2 = ()-> System.out.println("fly()");	// 하나의 실행문이면 {} 생략가능
				f2.fly();
						
		나. 파라미터 있고 리턴타입 없음
			ex. 
				@FunctionalInterface
				public interface Flyer2{				
					public abstract void fly(int n);				
				}
				
				Flyer2 f = new Flyer2(){
					public void fly(int n){
						@Override
						System.out.println("fly() = " + n);
					}			
				};
				f2.fly(10);
				
				// 람다표현식 (메서드에 집중)
				Flyer2 f2 = n -> System.out.println("fly() = " + n);	# 파라미터의 데이터타입 생략
																						# 파라미터 변수가 하나면 () 생략가능
		다. 파라미터 없고 리턴타입 있음										# 실행문 하나라 {} 생략
				ex. 
				@FunctionalInterface
				public interface Flyer4{				
					public abstract String fly();				
				}
				
				Flyer4 f = new Flyer4(){
					public String fly(){
						@Override
						return "Hello" ;
					}			
				};
				System.out.println(f.fly());				
				
				// 람다표현식 (메서드에 집중)
				// 아래와 같이 다수의 문장이 작성되면 {}, return 생략 불가
				Flyer4 f2 = () -> {
					System.out.println();
					return "Hello";
				};
				
				Flyer4 f2 = () -> "Hello";			# return 문장 하나만 존재하면 {} 와 return 생략 가능
				System.out.println(f2.fly());								
				
		라. 파라미터 있고 리턴타입 있음 
			ex. 
				@FunctionalInterface
				public interface Flyer5{				
					public abstract int fly(int n, int n2);				
				}
				
				Flyer5 f = new Flyer5(){
					@Override
					public int fly(int n, int n2){
						return n + n2;
					}			
				};
				System.out.println(f.fly(10,20));	
				
				// 람다표현식 (메서드에 집중)
				Flyer5 f2 = (int n, int n2) ->{return n + n2;};
				System.out.println(f2.fly(10,20));
				
				Flyer5 f3 = (n,n2) ->{return n + n2;};
				System.out.println(f3.fly(10,20));
				
				Flyer5 f4 = (n,n2) -> n + n2;						
				System.out.println(f4.fly(10,20));

	1) String
		
		가. java.lang.String
		나. 생성방법 2가지
		
			a. 리터럴 이용
				String s = "hello";
				String s2 = "hello";
				
				동일한 문자열인 경우 한 번만 생성됨
				(s == s2) -> ture				// == 은 주소값을 비교한다. 값를 비교하는건 equals()
				
			b. new 이용
				String s = new String("hello");
				String s2 = new String("hello");
				
				동일한 문자열일지라도 매번 생성됨.
				(s == s2) -> false
				
		다. 메서드
		https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/String.html
		
		라. 특징
			- String은 한 번 생성되면 변하지 않음
			- 메서드를 적용하면 적용된 새로운 문자열이 만들어짐.
			=>문자열 변경이 빈번하다면 String 사용을 지양해야 한다.
			- 대안으로 StringBuilder를 사용한다.
			
	2) StringBuilder
	
			가. java.lang.String
			나. 생성방법
				StringBuilder sb = new StringBuilder();
				
				String s = sb.toString();	// 최종적으로 String으로 변경해서 사용됨.
			다. 메서드
			https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/StringBuilder.html
			라. 특징
				- 한 번 생성된 문자열 자체가 변경됨.
				- 메서드를 적용하면 자신이 버퍼처럼 변경됨
