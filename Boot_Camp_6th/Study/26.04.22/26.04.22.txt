	2) DTO 클래스 작성
	- MyBaties에서는 필수		
	- 일반적으로 테이블당 하개씩 작성.
		ex. dept테이블용 DeptDTO.java
			 emp테이블용 EmpDTO.java
			 
	- DTO 클래스의 변수명은 테이블의 컬럼명과 일치하는걸 권장
		
		ex. dept 테이블 --------------------> com.dto.DeptDTO.java
			 
			 컬럼과 변수명이 같으면 명시적으로 매핑 x
			 deptno -------------------------> int deptno; getDeptno()/ setDeptNo()
			 dname --------------------------> String dname;
			 loc ----------------------------> String loc;
			
			 명시적으로 컬럼과 get/set을 매핑해줘야 한다
			 sal ----------------------------> int salary; getSalary()/setSalary()
			 
	- DTO 클래스에서 기본생성자와 getter/setter 메서드는 필수임
	
	==> DTO에 저장된 데이터는 자동으로 MyBaties에서 가져와서 SQL문에 사용됨.
		 반대로 SQL문 실행된 결과를 자동으로 DTO에 저장시킨다.

	3) 2개의 xml 파일이 필요.
		
		가. 설정파일
			- DB연도하기 위한 정보들을 포함한 파일.
			- src/com/config/configuration.xml
			
		나. mapper 파일
			- SQL문이 저장된 파일.
			- 테이블당 하나씩 생성.
			- src/com/config/테이블명Mapper.xml
			
				a. select 태그
					
					// 단일행
					<select id = "findByDeptno" resultType="com/dto/DeptDTO" parameterType="int" >
						select deptno, dename, loc
						from dept 
						where deptno = #{deptno} 	=> ; 제외,
					</select>							#{변수} 대신에 진짜 데이터로 치환됨.
															JDBC의 ? 역할.
				
					# 자바코드에서 호출 하는 방법:
					SqlSession session = sqlSessionFactory.openSession();
					T t =  session.selectOne(String);		// String = 태그 id
					T t =  session.selectOne(String, Object);		// Object는 #{변수}에 입력할 값
					# T는 resultType 과 같아야 한다.
					
					ex.
						SqlSession session = sqlSessionFactory.openSession();
						DeptDTO dto = session.selectOne("findByDeptno", 10);
						
					// 다중행	
					<select id = "findByAll" resultType="com.dto.DeptDTO">
						select deptno, dname, loc
						from dept	
					</select>
					
					# 자바코드에서 호출 하는 방법:		
					
					SqlSession session = sqlSessionFactory.openSession();
					# E = resultType
					List<E> list = session.selectList(String); # String = 태그 id
					List<E> list = session.selectList(String, Object); # Object = #{변수} 값
					List<E> list = session.selectList(String,Object, RowBounds); 
					
					ex.
					SqlSession session = sqlSessionFactory.openSession();
					List<DeptDTO> list = session.selectList("findAll");
					
					
				속성
				id	 : 태그 식별용
				
				resultType :
				select문 실행된 후 결과 레코드 하나를 저장할 때 사용하는 클래스. 패키지명 필수.select된 결과가 자동으로 저장됨. (***********)
				컬럼헤더이름으로 된 set메서드를 DTO에서 호출해서 저장한다.
				 ==> 컬럼 헤더와 DTO의 변수명이 다르면 set메서드 호출이 안된다.
						
				parameterType :
				sql 문에서 #{변수}에 해당하는 데이터 타입을 지정.
				전달된 값이 자동으로 #{변수}에 치환된다.
				
				b. insert문
					<insert id="insert" parameterType="com/dto/DeptDTO">
						insert into detp (deptno, dname, loc)
						valuese(#{deptno}, #{dname}, #{loc})
					</insert>
					
				parameterType이 DTO 이므로 #{deptno}는 deptno의 get메서드를 호출해서 
				DTO에서 파라미터를 가져온다.
				
				c. update문
					<update id="update" parameterType="com/dto/DeptDTO">
						update dept
						set dname=#{dname}, loc=#{loc}
						where deptno=#{deptno}
					</upeate>
				
				d.delete문
				<delete id="delete" parameterType="int">
					delete from dept
					where deptno = #{deptno}
				</delete>
				
		/////////// configuration.xml	///////////
			
		<?xml version="1.0" encoding="UTF-8" ?>
		<!DOCTYPE configuration
		  PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
		  "https://mybatis.org/dtd/mybatis-3-config.dtd">	// dtd파일, xml의 구조가 정의되어있다.
		<configuration>
		<properties resource="com/config/jdbc.properties"></properties>	// jdbc.property 를 소스로 불러온다.
		
		  <environments default="development">
			 <environment id="development">
				<transactionManager type="JDBC"/>	// 트랜잭션 처리 타입은 "JDBC"
				<dataSource type="POOLED">
				  <property name="driver" value="${jdbc.driver}"/> 	// .property의 값을 불러와서 쓴다 -> ${}}
				  <property name="url" value="${url}"/>
				  <property name="username" value="${username}"/>
				  <property name="password" value="${password}"/>
				</dataSource>
			 </environment>
		  </environments>
		  <mappers>
			 <mapper resource="com/config/DeptMapper.xml"/>	// DeptMapper.xml 설정
		  </mappers>
		</configuration>
		/////////////////////////////////////////
		
		/////////// DeptMapper.xml //////////////
		
		<?xml version="1.0" encoding="UTF-8" ?>
		<!DOCTYPE mapper
		  PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
		  "https://mybatis.org/dtd/mybatis-3-mapper.dtd">
		<mapper namespace="org.mybatis.example.BlogMapper">
		  <select id="selectBlog" resultType="Blog">		// id="" : 태그를 구분하기 위해 사용, 유일한 값 사용
			 select * from Blog where id = #{id}			// #{id} : jdbc의 ? 와 같은 열할
		  </select>
		</mapper>

	4) configuration.xml 파일 정보를 자바코드에서 사용할 수 있도록 설정
	
		String resource = "com/config/configuration.xml";
		InputStream inputStream = Resources.getResourceAsStream(resource);
