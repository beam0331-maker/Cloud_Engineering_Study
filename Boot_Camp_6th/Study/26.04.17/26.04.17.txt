2. 트랜잭션(transaction)

	1) 개념:
		1개 이상의 DML 작업들을 논리적으로 하나의 작업으로 묶어서 처리하는 개념으로, 묶음을 의미한다.
	
		ex. 
			계좌이체	(A에서 B로 500 이체)
			1. A계좌에서는 update (1000 -> 500)
			2. B계좌에서는 insert (null -> 500)
			
			1,2 두가지를 하나의 트랜잭션으로 두 동작 모두 성공했을때만 적용, 하나라도 실패하면 취소
			
			# 현재상황
			A 계좌								B 계좌
			1000
						
			# 성공
			A 계좌								B 계좌
			500									500
			
			# 실패
			A 계좌								B 계좌
			1000
			
	2) 트랜잭션 명령어 (TCL, DTL)
			
		가. commit
			- 트랝개션이 모두 성공했을 때 실제로 반영하는 명령어
			
		나. rollback
			- 트랜잭션이 하나라도 실패했을 때 실제로 모든 작업을 취소하는 명령어
			
	3) 특징
		- 시작 ~ 종료
		  시작은 DML을 사용하면 자동으로 시작됨
		  
		  ex.
		  
						<---- 트랜잭션 시작
				insert
				delete
				...
						<---- 트랜잭션 종료(commit, rollback)
						
	4) DBMS마다 트랜잭션 처리방법이 다름
	
		가. MySQL
			- auto commit으로 처리됨
			  따라서 트랜잭션으로 묶을 수 없음.
			- auto commit 비활성화해서 트랜잭션으로 처리 가능
				
				# autocommit 여부 확인
				show variables like 'autocommit%';
				
				# autocommit 비활성화
				set autocommit = false;
			
		나. Oracle
			- 명시적으로 commit/ rollback으로 트랜잭션을 종료해야 됨.

3. INSERT
	
	1) 용도
		- 새로운 레코드 생성
		- 단일행 생성 및 다중행 생성
		
	2) 단일행 생성 방법
		
		가. 컬럼명 명시
			
			문법: 
				// 트랜잭션 시작
				insert into 테이블명 (컬럼명, 컬럼며2, ...) values(값,값2,...);
				// 트랜잭션 종료 ( commit / rollback )
					
			특징:
				- 선택적으로 임의 컬럼에 값을 저장할 수 있다.
				- 지정하지 않은 컬럼에는 null 값이 저장된다. (지정되지 않은 컬럼은 not null 제약조건이 없어야 한다)
				- 컬럼명이 명시되기 때문에 가독성이 높다.
		
		나. 컬럼명 생략
			
			문법:
				insert into 테이블명 values (값, 값2, ... );
				
			특징:
				- 선택적으로 컬럼을 지정하지 않기 때문에 테이블의 컬럼 순서대로 값이 저장된다.
				- 반드시 테이블의 모든 컬럼에 값을 지정해 줘야 한다. ( 특정 컬럼 생략 불가 )
				- null 입력은 가능함
				- 컬럼명이 명시되지 않기 때문에 가독성이 낮음.
				
		다. 주의사항
			- 제약조건을 신경써야 한다.
			  Primary Key	: 반드시 값을 가지고 중복되지 않도록
			  Unique			: 유일한 값 저장
			  not null		: 반드시 값 저장.
			  
	3) 다중행 생성
		
		가. 서브쿼리 용
		
			문법:
				insert into 테이블명( 컬럼명,... )
				select  컬럼명,....
				from 테이블명;
				
				///////////////////////////
				# CTAS
				create table 테이블명
				as
				select 컬러명,...
				from 테이블명
				where 1=2;	// fales 이므로 레코드는 복사 되지 않음
				
				ex. 
					create table my_emp
					as 
					select empno, ename, sal
					from emp
					where 1=2;
					
					insert into my_emp(empno, ename, sal)
					select empno, ename, sal
					from emp
				///////////////////////////
			
		나. value list 이용
		
			문법:
				insert into 테이블명( 컬럼명,... )
				values (값, 값2, ... ), 
						 (값, 값2, ... ),
						 (값, 값2, ... ),
						 (값, 값2, ... );
						 
						 
			ex.
				insert into my_emp(empno, ename, sal)
				values (10, '홍길동1',500), (20, '홍길동2',500),(30, '홍길동3',500);

6. DDL(Data Definition language: 데이터 정의어)
https://docs.oracle.com/cd/E17952_01/mysql-8.0-en/create-table.html

	1) 용도
		
		- 객체(테이블, 인덱스, 사용자, ... )를 생성, 수정, 삭제 할때 사용한다.

	2) 특징
		
		- DDL은 자동으로 commit된다. ( rollback 불가 )
		
	3) 테이블 생성 문법
		
		CREATE [TEMPORARY] TABLE [IF NOT EXISTS] tbl_name
		(col_name  data_type,
		 col_name  data_type 제약조건 <= [NOT NULL | NULL] [DEFAULT {literal | (expr)} ]
													[AUTO_INCREMENT] [UNIQUE [KEY]] [[PRIMARY] KEY]
													FOREIGN KEY reference_definition
													check_constraint_definition
		
		DEFAULT {literal | (expr)} ]
		: INSERT할때 컬럼명을 지정하지 않으면 null 대신에 기본값이 설정됨.
		ex. writeday date DEFAULT now()
		
		AUTO_INCREMENT
		: 컬럼이 숫자인 경우, 값을 지정하지 않아도 숫자가 증가한다. ex) 게시판 넘버링
													
		reference_definition:
			REFERENCES tbl_name (key_part,...)	
			(REFERENCES master테이블 (master컬럼))
			[ON DELETE reference_option]
			[ON UPDATE reference_option]
			
		reference_option:
			RESTRICT | CASCADE | SET NULL | NO ACTION | SET DEFAULT
			
		# CASCADE	: 마스터 테이블의 키를 삭제하면 외래키의 데이터(튜플)도 삭제된다
		# SET NULL	: 마스터 테이블의 키를 삭제하면 슬레이브 테이블의 데이터(속성)가 null로 바뀐다
		// [회고포인트]: 참조 무결성(Referential Integrity)을 유지하기 위한 방법
		
		check_constraint_definition:
			[CONSTRAINT [symbol]] CHECK (expr) [[NOT] ENFORCED]
		# expr(expression) : 수식, 표현
			ex.
				CONSTRAINT CHECK (컬럼명 in ('M','F'))
		
	4) 데이터 타입
		
		가. 수치형
		
				- 정수형:
					tinyint		: (1byte)
					smallint		: (2byte)
					medinumint	: (3byte)
					int(integer): (4byte)
					bigint		: (8byte)
				
				- 실수형
					float
					double
					
		나. 문자형
		
				- char(n) : 글자 갯수 ( Oracle에서는 char(4) => 4byte)
								고정길이 문자형 처리(빈 부분을 공백으로 채움)
					
					ex. char(4): 영문이든 한문이든 4글자 저장가능
						 char(4) <- 'A' ==> 'A   '
				
				- varchar(n) : 글자 갯수 ( Oracle에서는 varchar2(n) => n byte)
									가변길이 분자형 처리(저장되는 크기만큼만 할당)
				
					ex. varchar(4) : 영문이든 한문이든 4글자 저장가능		
						 varchar(4) <- 'A' ==> 'A'
		
		다. 날짜형
		
			date		: 날짜만 저장, insert할때 curdate()
			
			time		: 시간만 저장, insert할때 curtime()
			
			datetime	: 날짜 + 시간, insert할때 now()
			
	# 게시판 테이블 샘플
	
		create table if not exists board
		(
			num int PRIMARY KEY AUTO_INCREMENT,
			title varchar(100) NOT NUlL,
			author varchar(10) NOT NUlL,
			content varchar(500) NOT NUlL,
			writeday datetime DEFAULT now(),
			readcnt int DEFAULT 0
		);
		
6. 테이블에 제약조건 설정방법
	
		1) 테이블 작성하면서 제약조건 설정
		
			- create만 필요
			
			가. 컬럼레벨
				
				- 테이블의 컬럼을 설정하면서 제약조건을 같이 설정
				- 5가지 제약조건 모두 사용 가능
					: Primary key, unique, not null, check, foreign key
				
				문법:
					create table NOT EXITSTS 테이블명
					(	컬럼명 데이터 타입 제약조건,
					...
					);
					
				ex. 
					create table if not exists board
					(
						num int PRIMARY KEY AUTO_INCREMENT,
						title varchar(100) NOT NUlL,
						author varchar(10) UNIQUE,
						content varchar(500) NOT NUlL,
						writeday datetime DEFAULT now(),
						gender char(4) CONSTRAINT CHECK (gender in ('M','F')),
						readcnt int DEFAULT 0
					);		
			
			나. 테이블 레벨
				
				- 테이블의 컬럼들을 모두 설정하고 나중에 제약조건을 설정
				- not null을 제외한 제약조건 사용 가능
					: Primary key, unique, check, foreign key
				
				문법:
					create table NOT EXITSTS 테이블명
					(컬럼명 데이터 타입,
					컬럼명 데이터 타입,
					컬럼명 데이터 타입,
					...,
					제약조건1 (컬럼명),
					제약조건2
					);
					
				ex. 
					create table if not exists board3
					(
						num int AUTO_INCREMENT,
						title varchar(100) NOT NUlL,
						author varchar(10) NOT NUlL,
						content varchar(500) NOT NUlL,
						writeday datetime DEFAULT now(),
						gender char(4),
						readcnt int DEFAULT 0,
						
						CONSTRAINT PRIMARY KEY(num),
						CONSTRAINT CHECK (gender in ('M','F')),
						CONSTRAINT UNIQUE (author)
					);		
		
		2) 테이블 만든후에 나중에 제약조건 설정
		
			- create + alter 필요	
			- alter문 이용한 제약조건 추가
			
			ex. 
				create table if not exists board4
				(
					num int,
					title varchar(100) NOT NUlL,
					author varchar(10) NOT NUlL,
					content varchar(500) NOT NUlL,
					writeday datetime DEFAULT now(),
					gender char(4),
					readcnt int DEFAULT 0
				);				
				
				가. not null 제약조건 변경(modify) 방법
					
					문법:
						alter table 테이블명
						modify add 컬럼명 데이터타입 not null
						
					ex.
						alter table board4
						modify title varchar(100) not null;
				
				나. not null 아닌 나머지 제약조건 추가(add) 방법
				
					문법:
						alter table 테이블명
						add CONSTRAINT 제약조건(컬럼명);		// 테이블 레벨 문법과 동일
					
					ex.
						# modify + add 같이 사용해서 primary key와 auto_increment 한꺼번에 설정
						alter table board4
						modify num INT AUTO_INCREMENT,
						add CONSTRAINT PRIMARY KEY(num);
						
						alter table board4
						add CONSTRAINT CHECK (gender in ('M','F'));
						
						alter table board4
						CONSTRAINT UNIQUE (author);
									
7. foreign key 설정
	
	create table master1
	(no int PRIMARY KEY,
	 name varchar(10) not null);
	 
	insert into master1 (no,name) values(1,'aa1');
	insert into master1 (no,name) values(2,'aa2');
	insert into master1 (no,name) values(3,'aa3');
	
	create table slave1
	(num int PRIMARY KEY,
	 ename varchar(10) not null,
	 no int ,
	 CONSTRAINT FOREIGN KEY(no) REFERENCES master1 (no) ON DELETE CASCADE
	 );
	
	insert into slave1 (num,ename, no) values(10,'slave1',1);
	insert into slave1 (num,ename, no) values(20,'slave2',2);
	insert into slave1 (num,ename, no) values(30,'slave3',3);
	insert into slave1 (num,ename, no) values(40,'slave4',4); -- 에러발생
	-- FOREIGN KEY이기 때문에 마스터 테이블의 key 범위에서 벗어날 수 없다.
	insert into slave1 (num,ename, no) values(50,'slave5',null);
	
	commit;
	
	# master1의 레코드
		
	 delete from master1 where no = 1;
	
	
	create table master2
	(no int PRIMARY KEY,
	 name varchar(10) not null);
	 
	insert into master2 (no,name) values(1,'aa1');
	insert into master2 (no,name) values(2,'aa2');
	insert into master2 (no,name) values(3,'aa3');
	
	
	create table slave2
	(num int PRIMARY KEY,
	 ename varchar(10) not null,
	CONSTRAINT foreign key (no) references master1 (no) on delete set null );
	
	insert into slave2 (num,ename, no) values(10,'slave2',1);	
	insert into slave2 (num,ename, no) values(20,'slave2',2);
	insert into slave2 (num,ename, no) values(30,'slave3',3);
	insert into slave2 (num,ename, no) values(50,'slave5',null);
	
	commit;
	
	
8. 테이블 삭제 및 절삭 (DDL 이기 때문에 rollback 안됨)

	- drop table if exists 테이블명, 테이블명2, ...;
	
	ex. 
		DROP TABLE IF EXISTS board;
		DROP TABLE IF EXISTS board2, board3;

	- trunate table 테이블명; -- 테이블내의 모든 레코드를 삭제
	
	* delete vs trunate
	  
	  - delete	: DML - ROLLBACK 가능
	  - trunate : DDL - ROLLBACK 불가능
	  
9. 테이블 수정
	https://dev.mysql.com/doc/refman/8.0/en/alter-table.html
	
	- 컬럼추가
		
		alter table 테이블명
		add column 컬럼명 데이터타입;
		
	- 컬럼추가
		
		alter table 테이블명
		drop 컬럼명;
		
	- 제약조건추가
		
		alter table 테이블명
		add 제약조건;
		
		alter table 테이블명
		modify 컬럼명 데이터타입 not null;
		
	- 컬럼이름변경
		
		alter table 테이블명
		rename column 컬럼명 to 새컬럼;
		
	ex.
		create table if not exists my_dept
		( no int primary key,
		  name varchar(10)
		);
		
		-- 컬럼 추가
		alter table my_dept
		add column address varchar(20);
		
		-- 컬럼 변경(크기변경)
		alter table my_dept
		add column address varchar(50);
		
		-- 컬럼 변경(크기변경)
		alter table my_dept
		modify address varchar(10);	-- 데이터가 저장되어 있다면 해당 데이터가 유지 가능한 크기를 지정해야된다
		
		-- 컬럼 이름변경
		alter table my_dept
		RENAME COLUMN address to addr;
		
		-- 컬럼 삭제
		alter table my_dept
		drop name;
