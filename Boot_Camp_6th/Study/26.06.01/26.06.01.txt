1. 프로세스 관리

	1) 개념: 실행중인 프로그램을 의미

	2) 특징: 
		- 부모/자식 관계로 구성됨 (계층적으로 구성됨)
		- 부모가 자식 프로세스를 생성하고, 자식프로세스가 실행된다
		  자식프로세스가 종료되면 부모프로세스에게 결과를 돌려줌
		- 모든 프로세스는 식별자를 가짐. (PID: 프로세스 아이디)
		- PID가 작을수록 중요한 프로세스이다.
		- 포그라운드(foreground) 및 백그라운드(background) 실행가능
		
	3) 프로세스 정보보기 			
		문법: 
			ps			# 현재 터미널에서 실행한 프로세스 정보만 출력.
			ps -ef	# 모든 프로세스 정보 출력
			___________________________________________________________
			UID          PID    PPID  C STIME TTY          TIME CMD
			user1     291512  148440  0 15:43 pts/0    00:00:00 ps -ef
			___________________________________________________________
			# 구성요소
			user1		: UID		(프로세스를 실행한 사용자)
			291512	: PID		(프로세스 아이디)
			148440	: PPID	(부모프로세스 아이디)
			0			: CPU 사용률
			15:43		: 시작시작
			pts/0		: 터미널
			00:00:00	: 사용시간
			ps -ef	: 실행 명령어
			
		#	ps -ef | grep 검색어 	# 현재 프로세스 중에 검색어만 출력ㅁ

	4) 주요 명령어
		
		- top		: 현재 실행중인 프로세스에 대한 정보를 주기적으로 출력	
		- fg 		: 백그라운드 작업을 다시 foreground 로 실행	
		- bg 		: 멈춰놓은 작업을 다시 background 로 실행	
		- &		: 백그라운드로 실행
		- ctrl + z		: 프로세스 중지	
		- ctrl + c		: 프로세스 종료	
		- kill pid		: 프로세스에 종료신호 보냄	
		- kill 9 pid	: 강제 종료
		
		
		# 실습1
			top		# 현재 실행 중인 프로세스
			ps -ef | wc -l		# 실행중인 프로세스 갯수
		
		# 실습2: foreground로 실행( 일반적으로 실행 )
			
			sleep 10		# 끝날떄 까지 기다리거나 ctrl + c 로 프로레스를 종료할 수 있다

		# 실습3: background 실행
		
			sleep 50 &		# background 실행
			
			jobs				# background 프로세스, 중지된 프로레세스 확인
			[1]+  Stopped                 top
			[2]-  Running                 sleep 50 &
			
			ps -ef | grep sleep
			user1       4597    3625  0 09:41 pts/0    00:00:00 sleep 100
			user1       4603    3625  0 09:42 pts/0    00:00:00 grep --color=auto sleep
			
			kill -9 4597	# PID 프로세서를 강제종료
			
		# 실습4: foreground --> background --> foreground
			sleep 100 		# foreground
			ctrl + z			# 프로세스 중지
			jobs				# 백그라운드 프로세스 확인
			
			bg	%1				# [1]에 해당하는 프로세스를 백그라운드로 실행
			jobs
			
			fg %1				#
			ctrl + c 		# 프로세스 종료
		
2. 프로세스 스케줄러

		- 정해진 시간에 특정작업을 반복처리하는 명령어
		
	2) 문법:	crontab [옵션]... <파일명>

		- 옵션
			-l	: 목록보기
			-r	: 스케줄러 삭제

		분		시		일		월		요일
		
		분 : 0~59
		시 : 0~23
		일	: 1~31
		월	: 1~12
		요일:  0~7	# 0/7 ==> 일요일
		
		ex.
			* 	*  *  *  *	:  매 1 분마다 작업
			0 	*  *  *  *	:  매 시간 0분마다
			30 2  *  *  *	:	매일 2시 30분 마다 작업
			0	0  1  1  *	:	매년 1월 1일 마다 작업
			
	# 실습
	
		# 1 . 파일 작성
			vim mycron.txt
			
		# 2 . crontab 파일 형식
			*/2 	*  *  *  *  echo "hello" >> hello.txt		#  매 1 분마다 작업
			* 	*  *  *  *  date >> date.txt
			
		# 3 . 실행 
			crontab mycron.txt
			
			man crontab 		# crontab 메뉴얼 확인
			crontab  -l			# 현재 사용자의 cron 확인
			crontab	-u user1 -1		# user1 사용자의 cron 확인
			
			crontab	-u user1 -r 	# user1 사용자의 cron 삭제

2. 쉘(Shell) 스크립트

	2) 문법
		- 반드시 첫라인은 다음과 같아야 한다.

			...

		- 권한 변경

4. Special Variable

	1) 개념: 쉘 내부에 미리 정의된 변수 의미. ( 내장 변수 )
		- $0 : 파일명
		- $1,$2... : 10부터는 중괄호 지정한다 . ex . ${10},${11}
		- $# : 스크립트에 전달된 인자의 갯수
		- $@ : 전달된 모든 인자 전체 ( 개별 항목으로 유지 )
		- $* : 전달된 모든 인자 전체 ( 모든 인자를 하나의 문자열로 합침 )
		- $$ : 현재 실행중인 쉘 또는 스크립트의 PID
		- $? : 바로 직전에 실행한 명령어의 결과코드 ( 성공 , 이외값 실패 )
		- $! : 가장 최근에 백그라운드로 실행한 프로세스 PID
		
	
	# 실습 
		# test3.sh 작성
		------------
		#!/bin/bash

		echo "file: $0"

		echo "arg1: $1"
		echo "arg2: $2"
		echo "$#: $#"		# 인자 갯수
		echo "$@: $@"		# 인자 모두 전달
		echo "$*: $*"		# 인자 모두 전달
		echo "$$: $$" 		# 현재 실행중인 스크립트 PID
		-------------
		
		chmod 700 test3.sh
		./test3.sh one two		
		file: ./test3.sh
		arg1: one
		arg2: two
		2: 2
		one two: one two
		one two: one two
		2164: 2164
		
	# 실습 . $? 
		$ ls
		test2.sh  test3.sh  test.sh		# 명령 성공
		$ echo $?
		0				# 이전에 실행한 명령이 성공했음
		
		$ ls /temp	# 존재하지 않는 디렉터리 ==> 명령실패
		ls: cannot access '/temp': No such file or directory
		$ echo $?
		2				# 이전 명령이 실패했음 알린다.

5. 연산자

	1) 숫자 비교 연산자( 수치 데이터만 가능하다 )
		
		- 조건식 문법: [[ 조건식 ]]		# 공백이 필수 이다, [ 조건식 ]은 과거문법

		- eq :	같다
		- ne :	같지 않다
		- gt :	크다
		- lt :	작다
		- ge :	크거나 같다
		- le :	작거나 같다
		
		ex. 
			$ num=10
			$ [[ $num eq 10 ]]		# 성공 / 실패
			$ echo "result: $?"
			result: 0

	2) 문자열 비교 연산자
	
		- =, ==	:	문자열이 같다
		- 	!=		:	문자열이 같지 않다
		- 	-z		:  문자열 길이가 0 이다
		-	-n		:	문자열길이가 0 이 아니다
		
		ex.
			name=hello		# "hello" 동일
			[[ $name == "hello" ]]		# 같은가
			echo "result: $?"
			
			[[ $name != "hello"]]		# 같지 않은가
			echo "result: $?"
			
			[[ -z $name ]]		# 길이가 0인가
			echo "result: $?"
			
			[[ -n $name ]]		# 길이가 0이 아닌가
			echo "result: $?"
			
		# 패턴 매칭 가능
			[[ $name == h* ]]		# h로 시작하는가
			[[ $name == *o ]]		# o으로 끝나는가
			
	3) 논리 연산자
		
		- &&	: 그리고( and )
		- ||	: 또는( or )
		- !	: 부정( not )
		
		ex.
			n=8
			[[ $n -eq 10 || $n -lt 10 ]]
			[[ $n -eq 10 && $n -lt 10 ]]
			[[ !($n -eq 10) ]]
	
	4) 산술연산자
	
		: +, -, *, /, %  지원한다
		
		문법:		$(( 연산 ))		# 소괄호 두번이다
		
		ex. 
			a=10
			b=3
			echo $((a + b))
			echo $((a - b))
			echo $((a * b))
			echo $((a / b))
			echo $((a % b))
	
	5) 증감 연산자
		: ++ , -- / 전치, 후치 지원한다
		계산 시	:	$(( 연산 ))
		
		ex.
			$ n=10
			$ n2=$(( ++n ))
			$ echo "$n,  $n2"
			11, 11

			$ x=10
			$ x2=$(( x++ ))
			$ echo "$x,  $x2"
			11, 10
			
	6) 파일 검사 연산자
	
		- e	: 파일디렉터리가 존재여부
		- f	:  일반파일 ( 텍스트 , 로그 등 )
		- d	: 디렉터리 여부
		- r	: 읽기가능 여부
		- w	: 쓰기 가능 여부
		- s	: 크기가 0 보다 크다
		- L	: 심볼릭 링크 여부
	
		ex. 
			[[ -e test.sh ]]		# test.sh 파일이 있는가
			echo $?
			
			[[ -d tmp/ ]]			# tmp가 디렉토리인가
			echo $?
			
			[[ -s test.sh ]]			# 크기가 0보다 큰가
			echo $?
			
			ln -s test.sh test_copy.sh
			[[ -L test_copy.sh ]]	# tmp가 디렉토리인가
			echo $?

10. 배열

	1) 문법:
		변수=(값 1 값 2 값 3) 		# 공백이 구분자, 인덱스는 0 부터
	
	2) 참조
		인덱스이용	: ${변수명[인덱스]}			# 0부터 지정.
		모두 조회	: ${변수명 [@]}, ${변수명 [*]}  
		슬라이싱		: echo "${변수명 [@]:시작위치}" 		
							ex. ${arr[@]:2} 		# 인덱스 2부터 끝까지
							
						  echo "${변수명 [@]:시작위치:갯수}"	
							ex. ${arr[@]:2:3}		# 인덱스 2부터 3 개
		
		배열길이 	: ${#변수명[*]}
		인덱스조회 	: ${!변수명[*]}
	
	
	3) 배열 삭제
	
		- 문법:	unset 변수명[인덱스]		# 지정된 인덱스만 삭제 
					
					unset 변수명				# 변수명 배열 삭제
		
	
	4) 추가
	
		- 문법: 변수명[인덱스]=값
				  
				  변수명+=(값 값2)		# 공백이 없어야 한다
