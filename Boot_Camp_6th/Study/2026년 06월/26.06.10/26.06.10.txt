1. 개념 
	: 컨테이너가 외부통신(www, host(wind.linux)) 및 컨테이너간 통신이 가능하도록 구성하는 네트워크 환경
	
2. 3가지 형태
	
	1) 외부통신: 
		- www(인터넷) 접근:
			기본적으로 지원된다.
			Docker에서 NAT를 지원한다. 		# NAT(Network Address Translateion) : 사설IP  --->  공인IP
		
		- host접근
			window: host.docker.inernal
			Linux	: hostIP
		
	2) 컨테이너통신 : 기본적으로 지원안됨
		- 컨테이너 IP로 접근은 가능함.
		- 컨테이너 재시작시 IP가 매번 바뀌기 때문에 사용하지 않음
		==> 동일 네트워크로 묶어 컨테이너 명으로 접근한다
	
3. docker 네트워크 정보보기 
	
	> docker network ls
	NETWORK ID     NAME         DRIVER    SCOPE
	92d5fb90d3cf   bridge       bridge    local	# docker가 사용하는 기본 네트워크
	df295ebadb60   full-stack   bridge    local
	15b04e576775   host         host      local
	7c9a5522b91c   none         null      local
	
	> docker inspect bridge
	> docker inspect host

7장: Docker Compose
//////////////////////////////////////////////////

https://docs.docker.com/reference/compose-file/services/ 참조

1. 개념 
	: 여러개의 컨테이너(서비스)를 한번에 정의하고, 한번에 실행/중지/삭제가 가능하도록 지원하는 도구.
	
2. 파일명 :
	  docker-compose.yaml/yml
	  compose.yaml/yml
	  
3. 특징
	- 필요할때 Dockerfile 사용가능.
	- 자동으로 동일한 네트워크로 묶인다 (****)
	- 여러 컨테이너를 한번에 시작 및 종료 할 수 있다
	- depends_on: 속성으로 컨테이너 실행 순서를 지정가능
	
4. docker compose 기본구조

	------------------------------
	services:			# 최상위 속성
	  web:				# 서비스명 ( 임의의 값 ), 하나의 컨테이너가 됨
		 image: nginx:latest		# base image 명
		 ports:						# Port Forwarding / -p 8080:80 과 동일
			- "8080:80"
		 depends_on:				# db를 먼저 실행하고 실행할것
			- db

	  db:					# 서비스명 ( 임의의 값 ), 하나의 컨테이너가 됨
		 image: postgres:18		# base image 명
		 environment:				# 환경변수, / Dockerfile: ENV SERVER_PORT=8080
			POSTGRES_USER: example			# key값은 대문자로 지정(관례)
			POSTGRES_DB: exampledb			
		 volumes:					# 영속성 위한 볼륨. -v 볼륨명:/var/lib/mysql
			- type: bind
			  source: ./proxy/nginx.conf
			  target: /etc/nginx/conf.d/default.conf
			  read_only: true
	------------------------------

5. 문법정리 

	1) services 속성
		- 최상위 속성 
		- 하위에 여러 서비스를 가질 수 있음.
		  각 서비스는 하나의 컨테이너라고 할 수 있다.
		  
		- 구성
			services:
				서비스:		# 하나의 컨테이너
					imager:	[<registry>/] [<project>/] <image> [:<tag>|@<digest>]
								# 사용할 docker 이미지(base image), 없으면 다운로드
								# hub에서 제공하는 offical image 또는 Dockerfile 로 만든 커스텀 이미지
					
					build: 	# Dockerfile에서 직접 이미지 생성
						
			ex.	sample12_TodoApp2_SpringSecurity>docker build -t my-front-app:v1 -f My_Dockerfile .
				backend:
					image: my-front-app:v1
					build:
					  context: sample12_TodoApp2_SpringSecurity	# dockerfile이 위치한 폴더
					  dockerfile: My_Dockerfile
				
					container_name:	# 컨테이너이름, --name spring-mysql-demo4
					command:				# 명령어. Dockerfile의 CMD, 덮어쓰기 가능
											ex. command: /bin/sh -c 'echo "hello $$HOSTNAME"'
											==> 컨테이너 실행시 SHELL에 접속해서 '명령어(문자열)'를 실행하라
												 ( 명령어가 문자열이면 반드시 -c )
												 
					entrypoint: 		# 명령어. Dockerfile의 entrypoint와 동일, 덮어쓰기 불가
					ports:				# 포트포워딩(포트매핑). -p 8080:80 동일
					expose:				# 포트 문서화. Dockerfile의 EXPOSE와 동일
