2. 식별자
	- 기본적인 명명규칙, 작성법 등 자바와 유사하다
	
	1) 기본 데이터형
		- "number"(수치데이터): 정수와 실수
		- "string"(문자데이터): 문자와 문자열 및 이스케이프 문자(\t)
		- "boolean"(논리데이터): true / false. 
			JS는 true, false가 아니여도 논리 값으로 처리 가능하다. (*)
			0, "", '' , null, nudefined, NaN => false // [외우기]
			false 가 아닌 값 => true
			
		- undefined: 변수가 초기화되지 않은 상태
			ex. var 변수명;
		- null: 객체없음(초기화는 된 상태)
			ex. var 변수명 = null;
		- NaN	: Not a Number
			ex. Number.parseInt("홍길동") // 잘못된 문자열을 숫자로 바꿀려할때
	
	2) 참조 데이터형
		: 객체형(배열)과 함수형 및 클래스
		- 객체: 두가지 형식이 존재
			map 형식 : {key:value} 
			배열 형식: [값, 값2,...] 
			
		- 함수: function{} ==> method와 유사하다.
		- 클래스: class ==> java의 class
		
		# 자바스크립트는 자바와 다르게 함수를 데이터로 취급한다
			==> 함수 또한 변수에 저장이 가능하다 (*)
	
	3) 변수
		가. 변수 선언(초기값은 undefied할당)
			
			var 변수명; => OLD
				- 변수명 중복이 가능
				- 블록 scope가 아닌 함수 scope를 따른다.
				  (함수로 만든 블록에서만 사용 가능, 함수가 아닌 블록에서 선언한 변수는 블록 밖에서도 사용가능)
				  ex. 
						// {} 스코프에서 선언 -> 함수 아니므로 외부에서 사용가능
						if(true){
						  var n2 = 100;
						}
						console.log(n2);  //  100
				-
			let 변수명; => ES6(권장), 자바문법과 유사
				- 변수명 중복이 줄가
				- 블록 scope를 따른다.({} 안에서 선언된 변수는 밖에서 사용불가)
				
		나. 변수 초기화
			변수명 = 값; // 런타임시에 지정된 값으로 할당된다.
			
		특징: 데이터형을 지정하지 않는다(실행단계에서 데이터형이 지정된다)
		 typeof 연산자를통해 데이터 타입을 확인 할 수 있다.
		 ==> var로 변수를 선언하면 나중에 데이터형이 지정된다.
		 
	4) 데이터 자동형변환
		가. *,/,-사용하는 경우 (+는 자바와 같이 문자열로 연결)
			ex. var test = “100” * 2; -> 200
			
		나. boolean값으로 자동 변환
			 : 0, "",’’, NaN, null, undefined 은 false로 변환된다
			 
	5) call by value vs call by reference
		: 자바와 같이 참조형은 변수를 전달받은 후 수정하면 같이 영향을 받는다.
			ex. 
				 let x = [10,20,30];
				 let x2 = x;				  
				 x2[0]= 100;
				 
	6) const: 상수 작성시 사용
		- let 변수와 동일하게 작동한다(block scope, 중복X)
		- 요소값 변경은 가능하다.(변수명에 할당된 주소를 바꾸는게 아니라 주소가 가르키는 값의 변경이기 때문 JS는 인식을 못한다)
		ex. 
			const NUMS = [10, 20, 30];
			NUMS[0] = 100;
			// const된 변수값(저장된 주소값)을 바꾸는는거 불가능		
			// NUMS = [20, 30, 40];

3. 연산자 - 대부분 자바와 동일하므로 차이점 위주로 정리한다.

	- 문자열 + 다른 데이터형이: 문자열로 연결된다.
	- / 연산자는 실수로 출력된다
		ex. 10/3 = 3.33333
		
	1) 동등 연산자
		가. equal 연산자( ==, != ): 값을 비교한다 			
			ex. 
				var w = 10;
				var w2= “10”;
				console.log( w == w2); // true
				
		나. identical 연산자( ===, !== ): 값과 데이터 타입까지 비교 (권장)
			ex.
				var w = 10;
				var w2= “10”;
				console.log( w === w2); // false
				
		- undefined를 비교할때는 === 연산자를 사용한다.
			ex.
				var x ;
				var x2 = null;				
				if( x === undefined ){ }// true
				if( x2 === undefined ){} // false
				
	2) 논리연산자
		- 기본적으로 자바와 같지만, 논리 값이 아닌 객체 비교가 가능하다.
		
		가. 값1 && 값2
			: 값1이 true면 값2가 선택되고
			  값1이 false면 값1이 선택된다.
			  (and 연산은 값1의 true일때 값2을 봐야 결과를 안다, 
				false일때는 값2를 보지 않아도 결과가 정해진다.
			ex. 10 && "홍길동" => "홍길동"
				 NaN &&  100 	 => NaN
		
		나. 값1 || 값2
			: 값1이 true면 값1이 선택되고
			  값1이 flase면 값2가 선택된다.
			(or 연산은 값1이 true면 true 이고
			flase일때는 값2를 알아야 결과를 안다)

			ex. 10 || '홍길동'=>  10
				 NaN || 100		=> 100
