1. CSS 적용 방법 3가지
	 1) inline 스타일
	  - inline = <p style="">
	  - style속성이용.
	  - 권장안함. ( 관리 및 디버깅 어려움, 가독성이 떨어짐 )
	  
	2) internal 스타일
		-	<head>
				<style>
				</style>
			</head>
	  - <style> 태그 이용
	  - .class명 => class명의 태그에 css 적용
	  
	3) external 스타일 
	  - external: <Link> 로 css파일을 불러온다
	  - 외부 css파일 이용
	  - 가장 추천
	  ( html과 css가 코드 분리되어 css코드가 많아져서 head태그가 길어질 때 유용,
		 또한 같은 스타일시트를 사용하여 여러 페이지에 적용할 때 브라우저가 캐싱하여 
		 새로운 페이지마다 다시 다운로드 하지 않음,
		 만약 head태그에 css가 있다면 html 파일 크기가 늘어나고 브라우저는 새로운
		 페이지마다 html의 한 부분인 스타일 태그를 매번 받게되어 속도가 느려진다. )
		- #id => id의 태그에 css 적용
		
 2. 우선순위 (*) 
  inline 스타일 > Internal 스타일 > external 스타일

캐스캐이딩과 명시도
	1. 캐스캐이딩: DOM 트리의 상위요소에서 정의한 디자인 속성이 하위 요소로 전달된다는 의미이다 . ( 상속의미 )
		- 하위에서 재정의 가능.
		
	2. 명시도: 선택자마다 우선순위가 정해져 있음을 뜻한다.나중에 설정 했다고 해서 덮어쓰는 것이 아니다 .
		- 기본 CSS 명시도 (Specificity) 우선순위:
		인라인스타일 > ID > 속성 > 태그
	  
	-명시도 가중치값 표현 ==> 쉼표를 제거한 값이 크면 우선순위가 높음. VSC에서 CSS에서 마우스 오버하면 확인가능함.
    인라인스타일 (1,0,0,0)	==> 가중치값은 1000 
    ID 			  (0,1,0,0)	==> 가중치값은 0100  
    class,속성   (0,0,1,0)	==> 가중치값은 0010 
    태그			  (0,0,0,1) ==> 가중치값은 0001  
	- 명시도는 결합해서 사용이 가능하다
	
		ex). ID+태그 ==> 가중치 (1,0,1)
		
		/* # css 명시도가 높음 ( 우선권이 높음 ) */
		#product-overview  h1{		
	      color: red;  
      }

1. 선택자

	- 전체 선택자
		<style type="text/css">
			 *{
				color:red;
			 }
		</style>
		
	- 태그 선택자
		<style type="text/css">
			/* h1 태그의 color 속성에 red를 적용한다.*/
			h1{
				color:red;
			}
			/* p 태그의 color 속성에 blue를 적용한다.*/
			p{
				color:blue;
			}
		</style>
		
	- id 선택자	// id는 유일하므로 중복되지 않는다
		<style type="text/css">
			#one {
				color: red;
			}
			#two {
				color: blue;
			}
		</style>

	- class 선택자	// 유일하지 않아 중복가능
	- class= "값 값 값" 으로 여려개의 class 지정 가능(*) //[그림으로 설명함]
	ex. 
		<style type="text/css">		
		/* .select > .aaa : select의 자식이 aaa 인 경우 */
		/*class가 select 자손인 aaa 인경우 */
			.select  .aaa {  
				color: red;
			}		
		/* class가 select이면서 aaa 인경우 => and */
			.select.aaa {   
				background-color: yellow
			}
		/* class가 select 또는  aaa 인경우 => or */
			.select , .aaa { 
				font-size: 30px
			}
		</style>>

		<body>
		 <ul>
			<li class="select aaa">홍길동</li>	// class가 select이면서 aaa인경우
			<li>이순신</li>
			<li class="select bbb">유관순</li>	// bbb지정 css가 없으므로 .select 만 적용된다
			<li>강감찬</li>
			<li class="aaa">강감찬</li>
			<li>
				<ul class="select">	// 캐스캐이딩
				  <li>AAA</li>
				  <li class="aaa">BBB</li>
				  <li>CCC</li>
				</ul>
			</li>
		 </ul>	
		</body>
	
2. DOM 트리 선택자
	- 자식 선택자: 자식관계 준 자식선택자 요소를 선택한다
	  부모선택자 > 자식선택자
	ex.
		# head	
		<style type="text/css">
			/* id="one"의 자식중 h1에게 css 적용 */
			#one > h1 {
				color: red;
				} 
		</style>
		# body
		<div id="one">
			<h1>Hello</h1>		// css 적용됨
			<p>Hello2</p>
			<div>
				<h1>world</h1>	// #one과 자손 관계이므로 css 적용 x
			</div>
		</div>
		
	- 자손 선택자: 자손관계 중 자손선택자의 요소를 선택한다
		부모선택자 자손선택자
		<style type="text/css">
			  #one  h1 {
				color: red;
			  }
		</style>
	
	- 형제(sibling)선택자: 
	  1) 선택자+형제선택자 = 인접한 바로뒤의 형제 요소를 선택한다
	  2) 선택자~형제선택자 = 인접한 모든 형제 요소를 선택를 선택한다
	  
	- 속성 선택자
		가. 선택자[속성]
		ex.
			<style type="text/css">
				[id]{
					color:red;
				}
			  /* a이면서 [id]의 속성 갖는 요소를 찾음 */
			  a[id]{
					background-color: blue;
				}
			</style>
			
		나. 선택자[속성=값]
		ex.
			<style type="text/css">
				[id="two"]{				
				}
			</style>	
		다. [속성^=값] = 속성의 value가 "값"으로 시작하는 요소를 찾는다
		라. [속성$=값] = 속성의 value가 "값"으로 끝나는 요소를 찾는다
		바. [속성*=값] = 속성의 value에 "값"이 포함된 요소를 찾는다

Box 모델

1. Box모델 (*) 
	Content: 텍스트 및 이미지등 실제 내용이 보여지는 곳
	padding: content 를 둘러싸고 있는 영역으로서 투명하다 안쪽 여백
	border : padding 과 content 를 둘러싸고 있는 영역
	margin : 다른 요소 간의 여백을 의미하는 영역으로서 투명하다 바깥쪽 여백
	
2. width, height
	- width
	- 블럭 레벨 요소는 너비(width)를 항상 기본값(width:100%)인 
     전체 너비를 사용한다.
   - 문법: width:100%|500px 형식
     width는 페이지 너비의 100%를 사용하지 않도록 설정할 때 중요하게 사용됨.
   - width:n% 는 가장 가까운 부모요소(컨테이너)의 width에 대해 n%만큼의 너비 적용을 의미.즉 부모가 100px이고 자식이 width:50% 라면 50px 너비가 적용됨.
	- height
	
   height:100% 로 지정하면 전체 페이지만큼 길어질것으로 기대했으나 
   아주 미미하게만 길어진다.
   이것은 부모 컨테이너의 가용 높이만큼만 그 길이가 길어지기 때문이다. (*****)
   따라서 특정요소를 기대한 높이만큼 길어지게 하려면 그 부모요소의 길이를 
   먼저 길어지게 설정해야 된다.
   ( section 보다 main, main 보다 body, body보다 
   html 요소 길이를 먼저 길어지게 설정해야 됨)
	
	# Style
	#x2{
     height: 500px;
   }
   #y2{
       /*  부모요소인 id=x2 크기를 500px 로 지정 했기 때문에 height 값 500 크기 사용됨.  */
      width:100px;
      height: 100%;
      background-color: powderblue;
   }
	
	# body
	<div  id="x2">		==> height: 500px
		<div id="y2">	==> height: 100% ->  500px (if. 50% -> 250px)
			AAA
		</div>
	</div>
	
	- box-sizing: border-box;
	- margin 속성:
		Box와 Box 사이의 여백을 제어하고 그 값들은 % 또는 px로 설정.
	- 문법1:
     
	  margin-top: 10px;
		margin-right: 10px;
		margin-bottom: 10px;
		margin-left: 10px;
	
	- 문법2: 축약 표현

      margin: top right bottm left;
			예> margin: 10px 10px 10px 10px;

      margin: top right|left bottm;
			예> margin: 10px 10px  10px;

		margin: top|bottm right|left ;
			예> margin: 10px 10px;

		margin: top|bottm|right|left ;
			예> margin: 10px;
			
	- 여백 상쇄: margin이 겹치는 두 요소 사이의 margin은 큰 값을 따른다(두 마진의 합 X)
	
	- border
	문법3: 축약
		border: width style color;
		ex. border: 2px dashed orange;

요소배치

1. display 속성

	1) 종류
	- display:block; 블럭 레벨로 표현
	- display:inline; 인라인 레벨로 표현
	- display:none; 요소를 랜더링 안함 랜더링 영역 유지 안함
	- display:inline-block; 인라인 처럼 한 줄에 표시되지만 블록 처럼 width/height 설정이 가능
	
2. position 속성 (*)
	
	- position 이전 문법으로는 블럭레벨/인라인레벨 정도 배치가 가능함.
	- position + top/rioght/bottom/lefr 이용하면 원하는 취치에 배치가능\\
	
	1) 종류:
		가. position: static
			- 기본방법 => static 생략가능
			- 블럭레벨: 세로배치 / 인라인레벨: 가로배치
			- top/right/bottom/lefr 지정해도 적용안됨 (*)
		
		나. position: relativ
			- top/right/bottom/lefr 적용됨
			- position:static 배치를 기준으로 상대적인 위치
			
		다. position: absolute
			- top/right/bottom/lefr 적용됨
			- 기준되는 box 내부에 위치한다
			- 기준은 2가지
			
				가. 부모(조상)기준
					- 부모가 position:relative 지정했을 떄
					 ex.
							<div> <== position:relative
								<p> <== position:absolute
				
				나. 화면(view port) 기준
					ex.
						<div> <== position: static
							<p> <== position:absolute					
			
		라. position: fixed
			- top/right/bottom/lefr 적용됨
			- 기준은 화면(view port)이 기준이된다.
			- 스크롤과 상관없이 화면의 고정된 위치에 존재한다

글꼴(font)
 
	- 글꼴 카테고리 : Generic Family
	
	ex. serif		: 꼬리가 있음
		 sans-serif	: 꼬리가 없음
		...
	- 글꼴 카테고리에 해당되는 실제 글꼴: font-family
	
	ex. serif			: 타임즈글꼴, Geogia, ...
		 sans-serif		: consolas, ...
		 
	- 글꼴설정방법(*)	
	=> font-family: font-family, font-family, font-family, ... , Generic Family
		ex. font-family: 타임즈글꼴, Geogia, ... , serif
			 font-family: consolas, ... , sans-serif
