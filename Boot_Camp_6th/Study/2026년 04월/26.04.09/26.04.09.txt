	5) 다중 catch 문
	
	문법:
		try{
			문장1; <--- ArithmeticException
			문장2; <--- NullPointerException
		}catch(예외클래스1 e){		// ArithmeticException
		}
		catch(예외클래스2 e){		// NullPointerException
		}
		catch(예외클래스3 e){		// Exception( 맨 위에 지정하면 우선으로 catch 하므로 문제 발생 )
		}									// Exception을 마지막에 두는건 관례( 인지 못한 에러를 처리하기 위해 )
	
	다형성 적용하면 Exception 만으로도 catch가 가능함. 하지만 상세하게 catch 하는걸 권장한다. (*********)
	주의할점: 반드시 catch문의 예외클래스는 계층구조에서 하위부터 지정해야 된다. (******)

2. 예외처리를 위임하는 방법
		
	개념:
	
		main(){	<------------	a() throws 예외클래스{	<--------	b() throws 예외클래스{
			try{	
				a()						b();											문장1;
			}catch{																		문장2; // 예외발생
			}											
		}								}												}

	문법: throws 예외클래스, 예외클래스2
		
		main 메서드가 아닌 임의의 메서드에서는 모두 throws 방법으로 위임하고
		최종적으로 main 메서드에서 try-catch로 처리한다.
