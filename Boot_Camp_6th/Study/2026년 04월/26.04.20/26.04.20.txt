Jdbc _ 강좌정리

JDBC ( Java Database Connectivity )

1. 개념
	
	-  자바프로그램언어와 DBMS연동하는 기술로서 DBMS에 독립적임
	
									JDBC
	자바프로그램 <------------------------> DBMS(MySQL, Oracle, MA-SQL, DB2,....)
	
2. 특징
	
	- DBMS종류와 무관하게 일관된 방법으로 접근이 가능 (DBMS에 독립적임)
	  어떤 DMBS건 동일한 메서드로 접근한다
	- JDBC는 비런타임 계열의 예외(SQLException)가 발생한다 -> thy-catch, throws로 예외처리해야한다.
	- JDBC는 기본적으고 auto commit임. ( 필요시 비활성화 가능 )
	- 일반 standart alone 환경 및 웹 환경에서도 JDBC 사용가능
	
3. 일관된 방법 구현

	1) 자바쪽에서 인터페이스 제공
		내부에 추상메서드(ex. public abstract void connect();)
	2) 인터페이시를 DMBS 벤더에 제공
	3) 벤더에서 클래스를 만들때 인터페이스를 구현
		ex. public class Oracle implements Connection{
				public void connect(){}
		}
			public class MySQL implemnets Connection(){
				public void connect() {}
		}
	4) 각 벤더마다 클래스파일들이 만들어지고 이 클래스파일들(*.jar)과
		자바 프로그램이 연동함.
		# *.jar 파일을 드라이버(driver)라고 부름.
	5) 벤더에서 제공해준 드라이버(dirver,jar파일)를 자바프로그램에서 사용할 수 있도록 설정이 필요함.
